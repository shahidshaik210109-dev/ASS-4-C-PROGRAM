How to Use
1. Download or open CO4_Assignment_4_Answers.pdf.
2. Read the explanations and review the C programs task by task.
3. If you want to test a program, copy its code into a .c file.
4. Compile the program using GCC:
   gcc -Wall -Wextra filename.c -o program
5. Run the executable:
   Linux/macOS
   ./program
   Windows
   program.exe
Note: Sample outputs in the PDF are representative. Actual output may
vary slightly depending on the compiler, platform, memory layout, and
runtime addresses. Verify each program by compiling and running it in
your environment before submission.
